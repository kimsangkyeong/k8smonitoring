# 컨테이너 모니터링 아키텍처 문서 세트 (OCP 4.20+ / Kubernetes 1.35+)

> 대상 환경: OpenShift Container Platform 4.20 · 4.22 복수 클러스터, 폐쇄망(disconnected/air-gapped), bastion 서버에서 `oc` 기반 정보 수집
> 기준 버전: OCP 4.20 이후 / Kubernetes 1.35 이후 아키텍처

## 비용 관련 안내 (기본요구 4)

권고 스택은 **OCP에 기본 내장된 무료 컴포넌트(Cluster Monitoring Operator / Prometheus / Alertmanager)** 를 1차로 사용하여 추가 라이선스 비용이 발생하지 않도록 설계했습니다. 상용 도구(예: 통합 관측 SaaS)는 비용이 크므로 기본 권고에서 제외했고, 다중 클러스터 통합 뷰가 필요할 때만 선택지로 제시합니다. 비용이 수반되는 선택지는 각 문서에서 "비용 주의"로 표기하고 차선안을 함께 제공합니다. 유료 옵션 적용은 승인 후 진행합니다.
